# dgo v1.0.0

This is the first stable major release of dgo. It supports Discord's public
REST, Gateway, and Voice APIs. The v1 series establishes the stable API
baseline: ordinary breaking API changes will require a new major version.

## Upgrade

```sh
go get github.com/darui3018823/dgo@v1.0.0
go mod tidy
```

Go **1.26.5 or newer** is required. When upgrading from v0.30.x, review the
following compatibility changes and the [migration guide](../Migration.md).

## Compatibility changes

- Toolchains older than Go 1.26.5 are unsupported.
- Gateway connections accept Bot credentials only. Prefer `NewBot(rawToken)`.
  OAuth2 bearer tokens remain supported only for applicable REST endpoints.
- Gateway intents now default to `IntentsNone`; set the smallest required
  intent set before calling `Open`.
- Messages do not parse mentions by default. Set `MessageAllowedMentions` when
  mentions are intentional.
- APIs removed by Discord or unsupported by Discord policy are disabled. Some
  former methods remain as source-compatible stubs that return typed errors.
- The legacy `wait` argument of `FollowupMessageCreate` remains for source
  compatibility, but created messages are always returned. New code should use
  `FollowupMessageCreateComplex`.
- `VERSION` and `Version()` are resolved from Go build information. Do not
  depend on a fixed version string.

## Voice and DAVE

DAVE/MLS end-to-end encryption support for Discord Voice has been implemented
and hardened.

- Adds MLS group state, key packages, commit/welcome handling, transitions,
  and ratchets.
- Fails closed instead of transmitting unencrypted audio while DAVE is active.
  Malformed nonces and RTP packet boundaries are also validated.
- Fixes the initial transition (ID 0), KeyPackage/group consistency, and
  connected-user roster handling during participant joins.
- `HeartbeatLatency()` returns `0` until the first heartbeat has been sent and
  acknowledged.

The following DAVE flows have been verified against Discord's live Voice
service: joining and playing Opus audio in a DAVE-enabled channel, leaving and
rejoining, repeated participant joins and leaves during playback, and
Gateway/Voice reconnection followed by DAVE initialization and a heartbeat ACK.

## Gateway and REST reliability

- Improves reconnect, resume, invalid-session, close-recovery, and heartbeat
  handling, including cancellation of obsolete reconnect attempts.
- Serializes and rate-limits outbound Gateway writes, and makes Voice
  connection operations and close handling synchronized and idempotent.
- Improves REST rate-limit bucket partitioning, global waits, bounded retries,
  replayable multipart uploads, and errors that do not expose credentials.

## Notable API additions

- Soundboard REST APIs, Gateway events, and state.
- Lobby, group DM, invite target, guild, and voice endpoints.
- Guild message search, paginated channel pins, and burst-reaction details.
- Application profile cosmetics, role gradient colors, activity launches,
  current modal inputs, and channel permission fields.

## Security

- Redacts Discord credentials, webhook and interaction tokens, and sensitive
  Voice data from logs.
- Bounds request bodies used for interaction signature verification.
- Adds CodeQL, Dependabot, `govulncheck`, and a documented vulnerability
  reporting policy.

## Verification

CI verifies the root module and standalone `linked_roles` and `voice_receive`
examples with `gofmt`, workflow lint, `go test -race ./...`, `go vet ./...`,
coverage floors, `staticcheck ./...`, `govulncheck ./...`, and a strict MkDocs
build.
