# dgo v1.1.0

This compatible minor release adds current Discord platform surfaces that fit
dgo's low-level REST and protocol scope. The v1 public API remains compatible;
no existing methods were removed or changed.

## Upgrade

```sh
go get github.com/darui3018823/dgo@v1.1.0
go mod tidy
```

Go **1.26.6 or newer** is required. Review the
[migration guide](https://github.com/darui3018823/dgo/blob/v1.1.0/docs/Migration.md)
when upgrading from v1.0.0.

## Application Identity Profiles

- Adds typed models for application identities, profile data, predefined stats,
  dynamic fields, and media values.
- Adds profile update and read methods, identity lookup by Discord user or
  external ID, and identity deletion.
- Handles Discord's `201 Created`/`204 No Content` split for profile updates.
- Escapes external identity path segments and encodes optional provider IDs.

See the [Application Identity Profile documentation](https://docs.discord.com/developers/resources/application-identity-profile)
and the [dgo usage guide](https://github.com/darui3018823/dgo/blob/v1.1.0/docs/WebhookEvents.md).

## HTTP Webhook Events

- Adds the Webhook Events outer and inner payload models.
- Adds constants for the documented webhook event names and payload types.
- Adds signature verification, bounded request parsing, body restoration, and
  the required empty `204 No Content` acknowledgement helper.
- Keeps event-specific data as `json.RawMessage` so consumers can decode it
  according to the event name.

See the [official Webhook Events documentation](https://docs.discord.com/developers/events/webhook-events)
for the endpoint requirements, retries, and event-specific payloads.

## Verification

The release is verified with root and standalone example-module tests and vet,
including the new REST endpoint and Webhook Events coverage. The full CI
workflow remains the release gate for race detection, coverage, static
analysis, vulnerability scanning, and the strict MkDocs build.
